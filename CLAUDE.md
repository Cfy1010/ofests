# CLAUDE.md

@AGENTS.md

- Les décisions d'architecture sont dans `docs/decisions/` (ADR numérotés).
  Les lire avant toute proposition qui touche à l'architecture.
- Definition of Done : `docs/definition-of-done.md`.
- Le PO (Cyrille) décide : proposer, ne pas trancher seul.
- Commits : pas de ligne Co-Authored-By.
- PR : pas de mention Generated with Claude Code.
- Issues : une retouche sans impact fonctionnel (espacement, coquille,
  commentaire, documentation, dépendance mise à jour sans changement de
  comportement) peut passer par une PR seule, dont la description donne le
  pourquoi. Dès qu’il faut un critère d’acceptation, un arbitrage ou plus
  d’une PR, une issue d’abord. La Definition of Done s’applique dans les deux
  cas.
