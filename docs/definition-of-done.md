
# Definition of Done



Un item n'est terminé que si les six critères ci-dessous sont satisfaits.

Ils s'appliquent à tout item, sans exception ni négociation en cours de route.



- Fonctionne en français et en anglais.

- Fonctionne sur mobile.

- Vérifié dans les deux thèmes, clair et sombre.

- Déployé sur Cloudflare Workers et vérifié en ligne.

- Aucune clé ni donnée sensible dans le dépôt.

- Documentation touchée à jour dans le même commit.
